If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view — link `styles.css` for the full token system and follow the rules in `readme.md`. If working on production code, copy assets and read the rules here to become an expert in designing with this brand.

Core rules to honour: deep navy for structure, gold as the sacred accent (never body text on light), purple as a signal colour only, calm-first with high-energy colour reserved for features/progress/games, large rounded cards, generous white space, Poppins-led UI with Playfair Display for sacred display and quotes, Lucide outline icons, and calm 300ms motion.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask a few clarifying questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
