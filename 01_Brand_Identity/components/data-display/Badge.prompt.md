Membership & gamification status pill. Status colour never overrides a card's category colour.

```jsx
<Badge status="active">Active member</Badge>
<Badge status="pending">Pending</Badge>
<Badge status="admin">Super admin</Badge>
```

Statuses: `active` (green), `pending` (amber), `suspended` (red), `points` (blue — knowledge points), `admin` (navy + gold authority), `achievement` (gold). Pass an 18–20px icon node via `icon`.
