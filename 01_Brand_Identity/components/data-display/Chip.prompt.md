Compact rounded label where colour conveys meaning. Use for streaks, week numbers, levels and category tags.

```jsx
<Chip tone="teal">Completed</Chip>
<Chip tone="orange">Live now</Chip>
<Chip tone="level" level={5}>Level 5</Chip>
```

Tones: `gold` (achievement), `teal` (completion), `purple` (reflection), `orange` (active/live), `navy`, `neutral`, and `level` (set `level={1..10}` for the matching game gradient). Keep labels short.
