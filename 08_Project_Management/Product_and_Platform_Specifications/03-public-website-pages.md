# Public website pages

Core public journeys: learn about MySAIYa, discover programmes/resources/events, find a centre, make contact, join or volunteer, and understand legal/privacy choices.

Each public page needs: clear purpose, accessible heading hierarchy, metadata, primary call to action, footer/legal links, responsive navigation, and defined empty/error states where it fetches content.

The complete route and navigation source is `apps/web/docs/10-sitemap.md`; do not add public routes here without updating it.
