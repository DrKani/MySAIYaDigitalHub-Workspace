# User roles

| Role | How granted | Primary scope |
|---|---|---|
| Visitor | anonymous | Public content and forms |
| Member | verified account/onboarding | Personal dashboard, learning, own records |
| Contributor | approved request | Create permitted drafts/submissions |
| Moderator | administrator assignment | Moderate assigned community/content workflows |
| Committee | invitation or approval plus MFA | Assigned Committee Hub work |
| Administrator | existing administrator assignment | Role, operational and audit administration |

Relationship-to-MySAIYa selected during onboarding is profile metadata, not authorisation. Privileged claims are granted and revoked server-side only. Suspended, deactivated and unverified users are explicitly handled account states, not roles.
